# Component Inventory

- **Layout**: MainLayout (Header, Sidebar/Nav, ContentArea)
- **UI Components**:
  - `Card`: Container for dashboard metrics/data.
  - `Panel`: Grouping element with title.
  - `Button`: Primary/Ghost/Full-width styles.
  - `Input`: Standard input fields, Password field (with show/hide), Captcha input.
  - `Modal`: Generic container for dialogs (Review, Approve, Reject).
  - `Table`: For admin review and application management.
  - `Feedback`: Toast notifications, Error boxes, Success boxes, Loading Skeletons.
  - `Navigation`: Sidebar, Header, Breadcrumbs.
- **Data Components**:
  - `Charts`: Used in dashboard (implied Recharts).
  - `Status Tag`: Labels for application status.
