# Design Analysis: SESSI Integrated Management System

This system is a management portal (Employer Portal) for ESSI Sindh.
It consists of several modules including Employer Registration, Inbox for notifications, and an Admin Dashboard for managing applications.

## Design System Overview
- **Typography**: Inter, Segoe UI, Arial, sans-serif.
- **Colors**: Primarily greens (`#067a35`, `#0b4d24`) for branding and green actions, with some red (`#b00020`) for errors/rejections.
- **Components**: Cards with borders and shadows, standard form inputs with labels and validation styling, modal dialogs, and panels for information grouping.
- **Responsive**: The design uses container queries and media queries to adapt to desktop, tablet, and mobile (sidebar collapse/hide on mobile).
